# Politique de sécurité

## Signaler une vulnérabilité

Pour signaler une vulnérabilité dans ESUP-Signature, utilisez le bouton
**Report a vulnerability** sur la page
[Security Advisories](https://github.com/EsupPortail/esup-signature/security/advisories).

Indiquez la version ou le commit concerné, la configuration pertinente,
les conditions nécessaires et l’impact observé. Les rapports peuvent être
rédigés en français ou en anglais.

Merci de garder les détails confidentiels pendant le traitement du signalement.
